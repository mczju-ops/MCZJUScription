# 对局场地矩形配置



## 11×17 统一场地（两角点 + 朝向）



框选 **11×17** 方块区域，插件自动解析：



| 区域 | 尺寸 | 说明 |

|------|------|------|

| 顶条 | 2×11 | 单人：预览条（内嵌 1.8×10.8 居中，召唤再下一波造物实体+头顶信息，不上场） |

| 间隔 | 1 格 | |

| 主网格 | 11×11 | 4×4 战斗/UI 矩阵（2×2 槽 + 1 格间隔） |

| 间隔 | 1 格 | |

| 底条 | 2×11 | 己方敲钟条（内嵌 1.8×10.8 居中，黄选绿确认敲钟） |



### 必填字段



| 字段 | 说明 |

|------|------|

| `arenaCornerA` | 矩形角点 A |

| `arenaCornerB` | 矩形角点 B |

| `arenaOrientation` | `SOUTH`（默认）/ `NORTH` / `EAST` / `WEST` |



### UI 图标旋转（可选）



| 字段 | 说明 |

|------|------|

| `arenaUiIconPitchDeg` | 绕 X 轴偏移（度，叠加在 -90° 躺平基准上） |

| `arenaUiIconYawDeg` | 绕 Y 轴偏移（度，叠加在朝向默认角上） |

| `arenaUiIconRollDeg` | 绕 Z 轴偏移（度，平面内滚转） |



对局内微调（需先 `/isc arena` 绑定场地）：



```

/isc arena ui icon show

/isc arena ui icon pitch -10

/isc arena ui icon yaw +5

/isc arena ui icon roll +15

/isc arena ui icon reset

```



`show` 会输出可抄进 room JSON 的数值。



### 主网格四行（自上而下）



| 行 | 单人 | 双人 |

|----|------|------|

| 0 | 敌后场（4 战斗槽） | 对方 UI 镜像 |

| 1 | 敌站场 | 敌站场 |

| 2 | 我站场 | 我站场 |

| 3 | UI 整备（腐肉/骨币/鱼干/商店） | 同左 |



### 双人模式顶条



顶 2×11 为**对方敲钟条**（灰玻璃，对方隔空双击结束回合），不再显示预览。



### 操作



- 战斗/UI 槽：怪物蛋 / 献祭剑 / 【射线】→ 左键射线 → 黄选 → 绿确认

- 底钟条 / 顶钟条（双人）：空手或任意物左键 → 黄选 → 绿确认 → 敲钟

- 商店槽：空手或任意物左键 → 黄选 → 绿确认 → 打开购卡



示例：`docs/example-inscription-play-arena.json`
